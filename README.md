# 🐾 Peddy Website

## 📌 Project Overview

Peddy Website is a dynamic and interactive web application that allows users to explore different pet categories through a clean and responsive user interface. When a user selects a category, the application fetches data from an external API and displays the corresponding pets instantly without reloading the page.

The project demonstrates strong proficiency in JavaScript, asynchronous data fetching, DOM manipulation, and responsive UI design. To improve the user experience, smooth loading animations such as a spinner are displayed during data retrieval, and the selected category button is visually highlighted with rounded corners.

## ✨ Key Features

### 1. Dynamic Data Fetching
Uses modern JavaScript to fetch pet data from an external API, enabling seamless content updates without page reloads.

### 2. Interactive Category Buttons
When a category is selected, the corresponding button updates visually with rounded corners and active styling to indicate the current selection.

### 3. Loading Spinner
Displays a loading spinner while API data is being fetched, providing users with real-time feedback.

### 4. Responsive Design
Optimized for desktop, tablet, and mobile devices, ensuring smooth layout adjustments across all screen sizes.

### 5. Modular Code Structure
The codebase is organized into reusable and maintainable functions, making future enhancements easy to implement.
